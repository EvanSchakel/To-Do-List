## 2026-05-06 - Missing Transactions & Open-in-View Overhead
**Learning:** Spring Boot's default `spring.jpa.open-in-view=true` holds database connections open during the entire HTTP request lifecycle. Furthermore, lacking `@Transactional(readOnly = true)` on service classes means Hibernate incurs dirty-checking overhead for all reads, and lacking `@Transactional` on modifying methods causes multi-query operations to use separate DB connections.
**Action:** Always add `spring.jpa.open-in-view=false` to `application.properties` to return connections to the pool faster. Use `@Transactional(readOnly = true)` at the class level and override with `@Transactional` on write methods in Spring Data JPA service layers to avoid dirty-checking on reads and ensure atomic database operations.
